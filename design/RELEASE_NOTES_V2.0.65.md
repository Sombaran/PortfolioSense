# Release Notes — v2.0.65

## Manual refresh during initial loading

Manual Refresh no longer fails just because an initial portfolio snapshot is
already being generated by another dashboard request. The request waits for
the in-flight snapshot and reuses it if it was created while waiting, avoiding
the prior "portfolio snapshot refresh is in progress" error when no cached or
local CSV data was available.

Non-manual requests retain their existing stale snapshot and local CSV fallback
behavior. The login popup shown after successful authentication summarizes this
change. Authentication,
rate limiting, and the server-side Stock API credential boundary are unchanged.
